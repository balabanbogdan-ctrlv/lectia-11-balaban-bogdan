# Laborator Git & GitHub - Lectia 11

Acest proiect conține exemplul practic pentru gestionarea codului sursă folosind Git, ramuri (branches), etichete (tags), acțiuni automate (GitHub Actions) și gestionarea dependențelor prin Node.js (npm).

## Tehnologii folosite
- Git & GitHub
- GitHub Actions (CI)
- Node.js / npm

## Cum se instalează proiectul
1. Clonează repozitoriul:
   \`\`\`bash
   git clone <link-repozitoriu>
   \`\`\`
2. Instalează dependențele:
   \`\`\`bash
   npm install
   \`\`\`
